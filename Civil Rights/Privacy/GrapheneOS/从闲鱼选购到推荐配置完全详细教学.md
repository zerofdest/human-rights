## 二手到货检查
依旧先看开发者模式里的oem是否能开，其次监管信息标签与商家给的是否一致。
> 开发者模式(Developer mode)：Settings（设置）=>About phone（关于手机）=>Build number（版本号）=>连续点击版本号约 7 次

另外，`设置 → 关于手机 → 电池信息(Battery information)`看循环次数，另外还有battery health。**机型也要核对好，否则后面刷的全是错的，遇到描述不符的机型立刻退货**

然后就是屏幕触控之类的，都可以自己随意检查

提供一个adb检查的思路，下载[platform-tools](https://developer.android.com/tools/releases/platform-tools)，然后给你解压的位置添加系统变量（按win键直接检索path就出来了）。开发者那里开usb调试，type-c连电脑给权限之后确认`adb device`没问题，然后运行[ADB_check.bat](https://github.com/zerofdest/human-rights/blob/main/Civil%20Rights/Privacy/GrapheneOS/ADB_check.bat)，会在当前目录生成一个检查结果的txt包括传感器之类

## 刷GrapheneOS
教程很多，简单来说就是进Fastboot输命令就结束了。这里想更新的要点具体如下
- 官方要求刷之前系统更新是怕版本太低，26年甚至25年新机就根本没必要，都android 15、16
- 官方首要建议刷机方式是[Web installer](https://grapheneos.org/install/web)，但是大陆有墙，web install等下载纯纯折磨王。大陆用户一律建议[Command-line Installer](https://grapheneos.org/install/cli)。

[Command-line Installer](https://grapheneos.org/install/cli)最大的好处可以将所有联网下载步骤预先解决，用IDM下载速度比web install快得多，而且实际刷机时间能够压缩得非常短（我似乎也就三分钟都未必有），不稳定性比较低和手机电量也基本不用管。再者，现在的[Command-line Installer](https://grapheneos.org/install/cli)下完三个文件点个.bat就结束了，实际相当简单与傻瓜

| 线材速率 | 建议至少5Gbps(USB 3.0、USB 3.1 Gen 1、USB 3.2 Gen 1)，10Gbps更好(USB 3.1 Gen 2、USB 3.2 Gen 2) |

### 输命令环节
```powershell
fastboot --version
```
确认系统变量正确设置以及版本不低于 `35.0.1`

关机之后同时按住音量减小键（Volume Down）+ 电源键（Power）直到出现 Bootloader 界面

台式优先用主板背面接口，不要用USB Hub 或扩展坞\
然后有线连手机
```powershell
fastboot devices
```
确认输出是否正常
```powershell
fastboot flashing unlock
```
按一下音量键调到
```text
Unlock the bootloader
```
随后按电源键确认。

在[Releases](https://grapheneos.org/releases)找到**对应机型**之后下`Install zip`、`Install zip signature`\
还有一个需要下的在https://grapheneos.org/install/cli#obtaining-factory-images \
即[the factory images public key (allowed_signers)](https://releases.grapheneos.org/allowed_signers)

其中体积最大的是`Install zip`，推荐直接IDM秒下

三文件放一个文件夹，在当前目录右键打开terminal\
现在目录大概是这样的
```text
├── allowed_signers
├── .zip
└── .zip.sig
```
执行签名验证：
下面的命令要把最后的.zip.sig < .zip替换为你实际的.zip.sig文件名以及.zip文件名（带扩展）\
```powershell
ssh-keygen -V
cmd /c 'ssh-keygen -Y verify -f allowed_signers -I contact@grapheneos.org -n "factory images" -s .zip.sig < .zip'
```
```text
Good "factory images" signature
```
说明签名验证成功
然后在当前目录解压.zip

```text
├── allowed_signers
├── .zip
├── .zip.sig
└── /
    ├── flash-all.bat
    ├── flash-all.sh
    └── ...
```
直接运行`flash-all.bat`

刷完之后，重锁bl。和之前一样音量选择电源确定
```powershell
fastboot devices
fastboot flashing lock
```
然后就是首次启动了。黄色警告是正常的\
记得关oem
